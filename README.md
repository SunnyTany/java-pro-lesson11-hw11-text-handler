# File Management Utility (Java NIO API)

Простая консольная утилита на Java для демонстрации работы с современным интерфейсом Java NIO (Non-blocking I/O). 

Программа позволяет создавать файлы, записывать в них данные и считывать содержимое, используя актуальные методы обработки путей и исключений.

## 🚀 Особенности
- ***Java NIO API***: Использование интерфейса Path и методов класса Files (createFile, writeString, readString).
- ***Автоматизация***: Автоматическое создание родительских директорий, если они отсутствуют.
- ***Robust Error Handling***: Реализована иерархия обработки ошибок через кастомное unchecked исключение FileProcessingException.
- ***Clean Code***: Логика работы с файловой системой полностью инкапсулирована в классе FileHandler.

## 🛠 Технологии
- **Java 11+** (используется Path.of и Files.writeString/readString)
- **Maven** (опционально, для структуры проекта)

## 📁 Структура проекта

app.Main — точка входа, содержит логику взаимодействия с пользователем и общую обработку ошибок.

app.FileHandler — сервисный класс для манипуляций с файлами.

app.FileProcessingException — кастомное исключение для управления ошибками ввода-вывода.

## 💻 Пример работы
При запуске программы выполняется следующая последовательность действий:
1. Проверяется наличие директории files/.
2. Создается файл myfile.txt.
3. В файл записывается строка "Super information.".
4. Происходит чтение данных из файла и вывод в консоль.

Ожидаемый вывод:

textCreated files/myfile.txt

Recorded in files/myfile.txt

CONTENT: Super information.

## ⚙️ Установка и запуск
- Склонируйте репозиторий или скопируйте файлы в вашу IDE.
- Убедитесь, что установлена JDK версии 11 или выше.
- Скомпилируйте и запустите класс Main:
  bashjavac app/*.java
  java app.Main

## ⚠️ Обработка исключений
Программа использует кастомную систему обработки ошибок для обеспечения стабильности и информативности вывода:

- **Файл уже существует**: перехватывается IOException в методе createFile.
        Error creating a file by path: ... и выброс FileProcessingException.

- **Отсутствие доступа**: ошибка прав доступа (ReadOnly или системные ограничения).
    Информативное сообщение об ошибке записи/чтения и остановка процесса.

- **Ошибка пути**: некорректные символы в названии файла или пути.
    Сообщение о невозможности обработать путь и проброс исключения в Main.

### Иерархия исключений:
- Низкий уровень: java.nio.file.IOException (базовое исключение системы ввода-вывода).
- Средний уровень: FileHandler перехватывает системную ошибку, выводит понятное сообщение в sout и оборачивает её в FileProcessingException.
- Верхний уровень: Класс Main ловит FileProcessingException, предотвращая аварийное завершение программы («крэш») и выводя финальное уведомление об ошибке приложения.
